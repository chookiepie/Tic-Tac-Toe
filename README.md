# Tic-Tac-Toe
Lets play a 2 player interactive classic Tic Tac Toe! Programmed It with the help of C.
In my game we have 2 players playing as X and O and tagging their symbols in grid by assigning the coordinates of each cell in the grid from 1-9. If the player chooses an already taken spot or enters and invalid range, other than 1-9, it will tell us that the entered value is invalid and ask us to enter another value.
As a beginner coder it was fun and challenging to code this mini game either ways it taught me alot of concepts along the way. I hope you enjoy my mini project!
